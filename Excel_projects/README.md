- What the file contains

This Excel file contains a structured transaction dataset representing user activity across different categories such as Crypto, NFT, and DeFi.
The data is organized using Excel Tables to ensure scalability, consistency, and ease of analysis.

The workbook includes:

A transactions sheet with raw transactional data

An analysis sheet with key aggregated metrics

- Metrics calculated

The analysis sheet includes the following metrics:

Total transaction amount

Average transaction value

Total number of transactions

Number of transactions by category (Crypto focus)

Total transaction amount for Crypto-related activity

High-value transaction flag based on business rules

These metrics are calculated using structured references and conditional aggregation formulas.

- Why it’s useful

This file demonstrates how Excel can be used as an analytical tool to:

Transform raw data into structured, analysis-ready tables

Apply business logic directly within datasets

Produce clear, decision-oriented metrics without manual recalculation

The approach reflects real-world data analysis workflows commonly used in business, finance, and crypto-related environments.
